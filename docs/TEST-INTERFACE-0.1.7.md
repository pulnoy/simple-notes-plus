# Test Simple Notes+ 0.1.7

Installer l’APK de test par-dessus la version de test existante.

## Navigation des dossiers
- Par défaut, ouvrir le tiroir avec le bouton en haut à gauche ou en glissant de gauche à droite.
- Choisir Toutes ou un dossier : le tiroir se ferme et les notes correspondantes apparaissent.
- Ajouter un dossier avec le bouton du tiroir ; utiliser les trois points pour renommer ou supprimer.
- La suppression d’un dossier conserve ses notes dans Toutes.
- Dans Réglages → Apparence, désactiver Tiroir de dossiers : l’accueil affiche uniquement les dossiers et l’entrée Toutes. Ouvrir un dossier pour voir ses notes ; le bouton en haut à gauche revient à la vue des dossiers.
- Réactiver le réglage pour retrouver le tiroir. Le choix est conservé au redémarrage.

## Couleurs
- Le mode Clair/Sombre règle la luminosité ; la palette Jaune/Bleu/Violet/etc. règle les couleurs.
- Pour conserver l’apparence jaune, choisir explicitement Jaune. Une ancienne sélection Dynamique est respectée et utilise maintenant réellement les couleurs Android.
- Tester Jaune puis Bleu ou Violet : accueil, bouton +, cases cochées, lecteur vocal et réglages doivent suivre la palette.
- Dynamique prend les couleurs du téléphone, avec un aperçu correspondant ; il est disponible à partir d’Android 12.
- Les couleurs personnalisées attribuées aux notes restent indépendantes de la palette de l’application.

- Vérifier une photo, la lecture d’un mémo vocal et la synchronisation Drive déjà configurée.
